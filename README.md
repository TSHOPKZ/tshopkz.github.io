# TSHOP — прайс на сборки

Сайт: https://tshopkz.github.io

`prices.json` обновляет бот TSHOP после каждой синхронизации складов дистрибьюторов. Руками его менять не нужно.
Сборки и детали описаны в репозитории бота: `site_data/builds.json` и `site_data/parts.json`.

## Служебное

- `tools/gen_pages.py` — короткие адреса сборок `tshopkz.kz/1041` (папки `/1041/index.html` с превью для WhatsApp/Instagram и переходом на карточку). Запускать после появления новых сборок: `python3 tools/gen_pages.py`. Номера без папки всё равно открываются через `404.html`, но без превью.
- `tools/gen_thumbs.py` — уменьшенные превью фото для списка (`img/t/N.jpg`). Сайт сам покажет оригинал, если превью ещё нет.
- Часы работы — константа `HOURS` в `index.html` (формат `10:00–20:00`); пока пустая — строки про часы не показываются.
